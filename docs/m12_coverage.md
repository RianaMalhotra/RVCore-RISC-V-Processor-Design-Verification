# Milestone 12 — Measured differential functional coverage

The `test_rv32i_differential.py` cocotb test writes `verification/reports/rv32i_functional_coverage.json` after passing independent Python-oracle comparisons. `verification/check_coverage.py` checks this report in GitHub Actions.

## Coverage points and minimum gates
- 21 supported integer operations: each must be exercised at least 100 times; **21/21 operation bins hit**.
- Legal/illegal decoding: 3,801 legal and 64 invalid instruction stimuli.
- Operand sign categories: zero, positive, and sign-bit-set (negative interpreted as signed) must all be exercised.
- Deterministic seed: `0x20261025`; includes directed boundaries and randomized inputs.

The JSON report contains measured **test stimulus bins**, not instrumented RTL toggle, statement, branch, FSM, or cross coverage. The 21/21 figure applies only to the implemented integer execution module and defined bins; it is **not 100% RISC-V ISA or SoC coverage**. Existing CPU architectural scoreboards, negative fault tests, and SVA provide additional assertions but are not aggregated into this percentage.

Run `make test-rv32i-differential && python3 verification/check_coverage.py` from the repository root. The report is generated by the test and can be published as a CI artifact.
